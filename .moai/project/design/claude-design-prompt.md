## 복사할 프롬프트

```text
제주 여행지의 투어 프로그램을 소개하고 온라인 신청을 받는 웹사이트의 화면을 디자인해 주세요.
여행객용 화면 7개와 관리자 대시보드 1개가 필요합니다.

[서비스 개요]
- 서비스 이름은 "숨비투어 / Soombi Tours"입니다. 해녀가 물 위로 올라와 내쉬는 '숨비소리'에서 따온 이름입니다.
  태그라인: "제주의 숨결을 따라 걷는 하루" / "Breathe in Jeju, one guided day at a time."
  로고는 이름을 쓴 간단한 워드마크면 충분합니다.
- 여행객은 투어를 둘러보고, 날짜·시간별 회차를 골라 신청합니다. 온라인 결제는 없습니다.
  가격은 "1인 45,000원 · 현장 결제" 같은 안내 문구로만 보여 줍니다.
- 비회원도 신청할 수 있고, 회원(이메일+비밀번호)은 로그인 후 신청하고 "내 신청 내역"을 볼 수 있습니다.
  비회원은 신청 내역 조회 화면이 없고, 접수 확인 이메일로만 확인합니다.
- 각 회차에는 정원이 있고, 신청 인원 수만큼 자리가 줄어듭니다(3명 신청 = 3자리).
  정원이 다 차면 회차가 "마감"으로 바뀌어 더 이상 선택할 수 없습니다.
- 한국어와 영어를 지원합니다. 모든 화면 상단에 KO / EN 전환을 두고, 영어 문구가 더 길어져도 레이아웃이 깨지지 않게 해 주세요.

[분위기와 스타일]
- 밝고 깔끔한 여행 사이트 느낌. 흰 바탕에 큰 제주 풍경 사진(바다, 오름, 돌담, 유채꽃)을 시원하게 씁니다.
- 포인트 색은 제주 바다 청록 #00737A 하나만 씁니다(hover #005A60, 연한 배경 #E6F3F2).
  주요 버튼("신청하기")과 링크에만 사용합니다.
- 나머지 색: 배경 #FFFFFF, 카드·섹션 배경 #F3F8F8, 본문 글자 #1A2B2E, 보조 글자 #4F6168,
  구분선 #D5DFE1(장식용), 입력창 테두리 #7C8E93, 포커스 링 #00737A 2px.
- 상태 배지(글자/배경): 모집 중 #0B6B4F/#E2F4EC, 마감 #4A5358/#ECEFF1, 대기 #8A5000/#FFF3D6,
  확정 #1D5FA8/#E6EFFB, 취소 #B3261E/#FDECEA. 배지에는 글자와 아이콘을 함께 넣습니다.
- 사진 위에 글자를 얹을 때는 #1A2B2E 60% 어두운 오버레이를 깝니다.
- 글꼴은 Pretendard 하나로 한글·영문을 모두 씁니다. 제목 700, 본문 400.
  크기(PC/모바일): Display 48/32px, H1 36/26px, H2 28/22px, H3 20/18px, 본문 16px, 보조 14px,
  배지 13/12px, 버튼 16px(높이 48px). 한글은 단어 단위로 줄바꿈합니다.
- 정보가 잘 읽히는 것이 화려한 효과보다 중요합니다.

[기기]
- PC(1440px 폭)를 기준으로 먼저 디자인하고, 각 화면의 모바일(375px 폭) 버전도 함께 보여 주세요.
- 관리자 대시보드는 PC 화면만 있으면 됩니다.

[여행객 화면]
1. 홈(랜딩)
   - 제주 풍경 대표 이미지와 한 줄 소개, "투어 둘러보기" 버튼
   - 투어 카드 목록(대표 사진, 투어명, 소요 시간, 가격 안내, 가장 가까운 회차 날짜)
   - 신청 방법 3단계 안내(투어 선택 → 회차 선택 → 신청 정보 입력)
   - 하단 정보(문의 연락처 자리, 개인정보 처리방침 링크)
2. 투어 목록
   - 모든 투어를 카드 그리드로 보여 줍니다. 모집 중인 회차가 없는 투어는 "모집 마감" 표시.
3. 투어 상세
   - 사진 여러 장, 투어 소개, 소요 시간, 집결 장소, 가격 안내 문구
   - 회차 목록: 날짜, 시간, "남은 자리 4 / 15" 표시, 마감된 회차는 흐리게 처리하고 "마감" 배지
   - 회차를 고르면 활성화되는 "신청하기" 버튼(PC에서는 오른쪽에 따라 내려오는 요약 박스로 제안)
4. 신청 정보 입력
   - 선택한 투어·회차 요약
   - 비회원으로 계속 / 로그인 후 신청 선택(로그인 상태면 이름·이메일 자동 입력)
   - 입력 항목: 이름, 이메일, 연락처, 인원 수, 요청 사항(선택)
   - 인원 수는 남은 자리보다 많이 고를 수 없고, 넘으면 "남은 자리는 2자리입니다" 같은 안내를 보여 줍니다.
   - 개인정보 동의 영역:
     · [필수] 개인정보 수집·이용 동의 — 펼쳐 보면 수집 항목(이름, 이메일, 연락처, 인원),
       목적(신청 접수·확정, 안내 연락, 분쟁 대응), 보유기간(투어 종료 후 5년),
       "동의하지 않으면 신청할 수 없습니다" 안내가 보입니다.
     · [선택] 요청 사항 수집 동의 — 요청 사항을 적을 때만 필요, 투어 종료 후 바로 삭제.
       "동의하지 않아도 신청할 수 있습니다"를 명시합니다.
     · 필수와 선택은 서로 다른 체크박스로 분리합니다. 한 번에 모두 동의하는 버튼은 넣지 않아도 됩니다.
   - 요청 사항 입력란 아래에 "건강·장애 등 민감한 정보는 적지 마세요" 안내를 넣어 주세요.
   - 입력 오류 상태(필수값 누락, 이메일 형식 오류, 동의 미체크)와 제출 중 상태도 보여 주세요.
5. 신청 완료
   - "신청이 접수되었습니다"와 신청 내용 요약(투어, 회차, 인원, 상태: 대기)
   - "확정되면 이메일로 안내드립니다" 안내, 접수 확인 메일이 발송되었다는 문구
   - 비회원에게는 "회원으로 가입하면 신청 내역을 확인할 수 있어요" 같은 가벼운 안내
6. 로그인 / 회원가입
   - 이메일 + 비밀번호만 사용합니다. 소셜 로그인 버튼은 넣지 마세요.
   - 비밀번호 찾기 링크 포함
7. 내 신청 내역(회원 전용)
   - 신청 목록: 투어명, 회차 일시, 인원, 상태 배지(대기 / 확정 / 취소)
   - 신청이 없을 때의 빈 화면

[관리자 대시보드]
8. 회차별 신청 현황
   - 이 사이트의 관리자 화면은 Payload CMS 기본 관리자 화면을 쓰고, 이 대시보드만 그 안에 추가됩니다.
     Payload 관리자 화면처럼 차분한 회색 톤의 업무용 화면으로 디자인해 주세요.
   - 표시할 지표는 "회차별 정원 대비 신청 인원" 하나입니다.
     각 회차를 한 줄로: 투어명, 날짜·시간, 진행 막대("12 / 15명"), 상태(모집 중 / 마감)
   - 투어별로 묶어 보기, 날짜 순 정렬
   - 정원이 거의 찬 회차와 마감된 회차가 한눈에 구분되게 해 주세요(색만이 아니라 글자·아이콘으로도 구분).

[예시 콘텐츠 — 모두 가상]
- "한라산 영실 코스 반나절 트레킹" · 4시간 · 1인 45,000원 · 현장 결제
- "우도 자전거 일주" · 5시간 · 1인 38,000원 · 현장 결제
- "해녀와 함께하는 바다 체험" · 2시간 · 1인 55,000원 · 현장 결제
- 회차 예: 11월 20일(목) 오전 9:00, 정원 15명, 남은 자리 4
- 후기, 별점, "누적 1만 명 참여" 같은 수치는 넣지 마세요. 실제 데이터가 없습니다.

[넣지 말아야 할 것]
- 결제 버튼, 카드 입력, 장바구니
- 소셜 로그인, 카카오톡 알림 안내
- 비회원 신청 조회 화면
- 한국어·영어 외 언어 선택지

[접근성]
- 본문 글자와 버튼은 배경 대비가 충분해야 합니다(WCAG AA 기준).
- 상태(마감, 대기, 확정, 취소)는 색만으로 구분하지 말고 글자를 함께 표시해 주세요.
- 키보드로 이동할 때 포커스가 눈에 보이게 해 주세요.
- 모든 사진에는 대체 텍스트가 들어갈 자리를 고려해 주세요.

[결과물]
- 위 8개 화면(여행객 화면은 PC + 모바일, 대시보드는 PC)
- 버튼, 입력창, 회차 카드, 상태 배지, 투어 카드 같은 공통 컴포넌트 모음
- 색, 글꼴, 간격 등 디자인 토큰 정리
- 이후 Next.js(React)로 구현할 예정이니, 컴포넌트 단위로 나누어 정리해 주세요.
```

## 결과 검토 기준

Claude Design 결과를 받으면 아래를 확인합니다.

- [ ] 8개 화면이 모두 있고, 여행객 화면은 PC와 모바일 버전이 함께 있다
- [ ] 결제·소셜 로그인·비회원 조회가 들어가 있지 않다
- [ ] 회차의 "남은 자리"와 "마감" 상태가 분명하게 보인다
- [ ] 인원 수가 남은 자리보다 많을 때의 안내가 있다
- [ ] 필수 동의(보유기간 5년 포함)와 선택 동의(요청 사항)가 분리되어 있다
- [ ] 화면 상단·하단에 "숨비투어 / Soombi Tours"가 표시되고 포인트 색이 #00737A 하나뿐이다
- [ ] 상태 배지가 색 + 글자로 구분된다
- [ ] 영어 화면에서 긴 문구가 버튼·카드 밖으로 넘치지 않는다
- [ ] 가상 콘텐츠에 실제처럼 보이는 후기·별점·통계 수치가 없다

결과 문구 검수는 `moai-designer:design-slop-check`, 구현용 핸드오프 정리는 `moai-designer:design-handoff`로 이어갈 수 있습니다.
