# SPEC-DEPLOY-001 인터뷰 기록

> 대상: 로드맵 8번 "배포"의 1단계 "배포 기반" (`.moai/project/product.md` §7, 2026-11-12 개정 진행 순서: 관리자 운영 → 랜딩 → 배포)
> 진행: 2026-11-17, 오케스트레이터가 사용자와 진행했다. 아래 질문 문구는 위임 지시에 담긴 결정 내용을 바탕으로 다시 적은 요약이며, 답은 결정 내용 그대로다.
> 효력: 아래 6가지 결정은 이 SPEC을 구속한다. 초안 작성 중 다시 묻지 않는다.

## Q1. Vercel과 Supabase 계정이 있나요?

- **답**: 둘 다 이미 있다.
- 반영: `plan.md` §I(계정 만들기 단계 없이 프로젝트 만들기부터 안내)

## Q2. 사이트 주소는 어떻게 할까요?

- **답**: 우선 무료 `*.vercel.app` 주소를 쓴다. 자체 도메인은 나중에.
- 반영: REQ-DEPLOY-001(`NEXT_PUBLIC_SERVER_URL` = `https://<프로젝트>.vercel.app`), `spec.md` §5

## Q3. 지역은 어디로 할까요?

- **답**: Supabase 프로젝트는 서울 리전, Vercel 함수 리전도 서울(`icn1`)로 맞춘다.
- 반영: REQ-DEPLOY-009(`regions: ["icn1"]`), REQ-DEPLOY-014(실제 리전 확인), `plan.md` §I.1 2번

## Q4. 처음부터 공개하나요?

- **답**: 두 단계로 나눈다. 이번 SPEC은 공개하지 않는 미리보기 배포(검색에 잡히지 않고 알리지 않음)를 만든다. 보호 방식은 사용자 요금제에서 쓸 수 있는 것으로 정하되, 무료 Hobby 요금제가 무엇을 지원하는지 공식 문서로 확인해 한계를 있는 그대로 기록한다. 공개 출시는 2단계에서 한다.
- 위임된 판단의 결과: Vercel Authentication + 보호 범위 "All Deployments"(공식 문서상 모든 요금제 가능, 운영 주소까지 보호). Password Protection은 Hobby 불가, "Standard Protection"은 운영 주소를 보호하지 않음. Cron이 운영 배포에서만 실행되므로 미리보기는 `main`의 운영 배포에 보호를 건 형태. 검색 제외 표시를 이중 장치로 둔다. Cron 호출이 이 보호를 통과하는지는 공식 문서에 없어 실제 배포에서 확인한다(`plan.md` §B.1·§G R1).
- 반영: REQ-DEPLOY-012, REQ-DEPLOY-013, `spec.md` §5 2단계 목록

## Q5. 운영자 정보(상호·대표자·보호책임자·연락처)는요?

- **답**: 2단계에서 정한다. 이번 SPEC 범위 밖.
- 반영: `spec.md` §5

## Q6. 오래된 기록은 어떻게 지우나요?

- **답**: Vercel Cron(Hobby는 하루 한 번)으로 10분 지난 신청 시도 기록과 2년 지난 관리자 작업 기록을 지운다. 동의 고지의 IP 변환값 문구가 지금 "다음 신청 처리 때 삭제"라고 되어 있으니 실제 최대 보관 시간으로 고치고, 문구가 바뀌므로 `src/lib/consent.ts` 규칙대로 `PRIVACY_POLICY_VERSION`을 올린다. Cron 엔드포인트는 Vercel 문서대로 `CRON_SECRET` Bearer 값으로 보호한다.
- 위임된 판단의 결과: 경로 `/api/cron/cleanup`, 일정 `0 18 * * *`(UTC, 한국 시각 오전 3시대). 최대 보관 시간은 Hobby의 하루 한 번·시 단위 정밀도와 Cron 전달 누락 가능성을 넣어 계산한 "만든 때부터 늦어도 72시간"(`plan.md` §B.5).
- 반영: REQ-DEPLOY-007~010

## 이미 정해진 제품 규칙 (기존 SPEC과 프로젝트 문서 — 이 SPEC이 그대로 담는다)

- 필수 환경 변수가 없으면 서버를 띄우거나 DB에 연결하기 전에 이름만 보여 주고 멈춘다. 비밀값은 출력하지 않는다(SPEC-INFRA-001 REQ-INFRA-008·010)
- 신청 시도 기록은 원래 IP 문자열을 저장하지 않고 키 해시만 남긴다(SPEC-APPLY-001 REQ-APPLY-013)
- 문구를 바꾸면 `PRIVACY_POLICY_VERSION`을 바꾸고, 이미 접수된 신청의 버전 값은 그대로 둔다(SPEC-APPLY-001 REQ-APPLY-014, `consent.ts` 주석)
- 작업 기록은 덧붙이기 전용이며 관리자도 지울 수 없다. 2년 보관과 자동 삭제는 출시 전 항목이었다(SPEC-ADMIN-001 R20)
- 익명 미디어 읽기는 공개 투어 대표 이미지와 홈 대표 사진만(SPEC-TOUR-001 REQ-TOUR-005, SPEC-LANDING-001 REQ-LANDING-003)
- 실제 관리자 계정은 건드리지 않는다. 테스트는 `@example.test` 계정과 표식 데이터를 스스로 만들고 지운다
- 화면 문구는 한국어, 오류 문구는 영문(`error_messages: en`)
- Vercel Hobby는 비상업 용도 한정이며 상업 운영 시 요금제를 다시 본다(`tech.md` §5)
